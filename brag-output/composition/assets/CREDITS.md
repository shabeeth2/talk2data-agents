# Demo assets

- Demo data: Talk2Data's deterministic seeded retail source, queried through the local app. No uploaded or connected private data.
- Geist fonts: Vercel, SIL Open Font License 1.1; license included as OFL.txt.
- GSAP 3.14.2: GreenSock standard license, https://gsap.com/standard-license/. The distributed script retains its license notice.
- click.ogg and land.ogg: Kenney CC0 assets bundled with latent-spaces/brag. Public domain; https://kenney.nl/assets.
- ambient.m4a: original three-note synthesized ambient bed created for this demo using FFmpeg. No third-party music samples.

The composition follows the Brag skill: https://github.com/latent-spaces/brag (MIT). The video illustrates the app's working UI and starter queries; model tool loops are verified separately using a mock provider.
